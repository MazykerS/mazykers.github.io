JARVIS — Privacy Policy

Last updated: 13 November 2026

1. Who uses this app

JARVIS is a private, self-hosted personal assistant. It is used by exactly one person: the owner of the YouTube channel @mazyker, who is also the operator of the app. It is not offered to the public, and nobody else can sign in.

2. What data is accessed

With the owner's explicit consent through Google OAuth, the app reads data about the owner's own YouTube channel:

  • channel information and the list of the channel's own videos (titles, publish dates, durations, privacy status);
  • public counters such as views, likes, comments and subscriber count;
  • YouTube Analytics reports for the channel, such as views, watch time, average view duration, audience retention, subscribers gained or lost.

Scopes requested: https://www.googleapis.com/auth/youtube.readonly and https://www.googleapis.com/auth/yt-analytics.readonly. Both are read-only.

The app does not upload, edit, delete or publish videos, does not manage comments, and does not access any other Google service or anyone else's data.

3. How the data is used

The data is used only to produce statistics summaries for the owner and to help plan the channel's own content. It is not used for advertising, is not sold, and is not used to train AI models.

4. Storage and security

Data and the OAuth token are stored only on the owner's private server. The token is readable only by a dedicated system account, and access to the server is restricted to its administrator. Daily statistics snapshots are kept so that the owner can compare periods.

5. Sharing

The data is not shared with third parties. A text summary of the statistics may be processed by the AI model the owner uses for his own assistant, under that provider's terms, and only to answer the owner's own questions.

6. Retention and deletion

The owner can revoke access at any time at myaccount.google.com/permissions. After access is revoked, the token stops working and stored snapshots can be deleted from the server at the owner's request.

7. Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Contact

Questions about this policy: contact the channel owner through youtube.com/@mazyker.

Кратко по-русски

Данные хранятся на личном сервере владельца и третьим лицам не передаются. Отозвать доступ можно на myaccount.google.com/permissions.
